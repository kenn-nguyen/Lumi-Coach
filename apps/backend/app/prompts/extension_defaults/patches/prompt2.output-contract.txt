Additional output rules:
- `top_resume_goals` must contain exactly 3 ranked strings
- `summary_sentences` must be `1` or `2`; use `1` by default and `2` only when the role fit needs a second sentence
- `signal_map.support` must be exactly one of: `direct`, `adjacent`, `unsupported`
- `selected_storylines.strength` must be exactly one of: `high`, `medium`
- `selected_storylines` must contain 3-5 items, ordered by importance
- `selected_storylines[0]` is the summary anchor storyline
- every `selected_storylines` entry must include non-empty `anchor_role`, `anchor_bullet`, and `guardrail`
- `excitement_anchor` is required
- `excitement_anchor.placement` must be exactly one of: `summary`, `first_bullet_of_recent_role`, `both`
- `experience_emphasis.default_action` must be exactly one of: `keep`, `rewrite_all`
- every materially relevant recent role should appear in `experience_emphasis`
- `company_context_guidance` must be an array and may be empty
- `company_context_guidance.action` must be exactly one of: `preserve`, `add`, `revise`, `omit`
- `company_context_guidance.recommended_context` should be one short company/product context line, usually 8-18 words
- `company_context_guidance.recommended_context` should focus on company category, market, customer type, product area, or business model
- `company_context_guidance` must not include achievements, responsibilities, metrics, or candidate impact claims
- use `omit` when context would be speculative, redundant, or low-value
- `bullet_rewrite_instructions` should include only bullets that need rewriting
- `bullet_rewrite_instructions[].instruction` must be an object with exactly: `primary_message`, `primary_metric`, `mechanism`, `optional_context`, `do_not_include`
- `bullet_rewrite_instructions[].instruction.do_not_include` must contain strings only
- `flex_notes` is optional and must be a string or null; use `""` when unused
- Use `flex_notes` only for small non-critical strategy notes needed by future prompt variants
- do not emit `unsupported_signals` or any other field not present in this schema
- keep arrays concise and ordered by importance
