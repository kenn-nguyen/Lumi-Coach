# Builder Spec

Mode: Work-led

## Structural Lock

- Keep the left editor and right preview split.
- Keep toolbar and tab placement.
- Keep form ordering and section sequencing.
- Keep the preview dominant on the right.

## Visual Intent

- Editor should become a precise studio surface.
- Preview should sit on a cleaner framed stage.
- Tabs should be flatter and more anchored.
- Toolbar actions should be compact and disciplined.

## Components To Reskin

- builder page shell
- action toolbar
- left editor surface
- form fields
- section headers
- preview chrome
- tabs

## Tone

- quiet
- exact
- document-focused
- least decorative screen in the suite
