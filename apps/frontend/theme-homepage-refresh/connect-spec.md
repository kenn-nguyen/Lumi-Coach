# Connect Spec

Mode: Brand-led

## Structural Lock

- Keep progress messaging in the center.
- Keep success and failure state space.
- Keep retry/close affordances if present in the live page.

## Visual Intent

- Connect should feel like a clean transition state.
- It should visually relate to sign-in.
- It should be quieter than dashboard but still branded.

## Components To Reskin

- transition shell
- progress card
- status chips
- retry/return actions

## Tone

- calm
- trustworthy
- transitional
