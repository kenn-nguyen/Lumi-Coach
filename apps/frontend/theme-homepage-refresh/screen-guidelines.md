# Screen Guidelines

This file defines what may change visually on each live page and what must stay fixed.

## Core Correction

The theme should not be applied uniformly across the app.

There are two screen modes:

## Brand-Led Screens

- dashboard
- sign-in
- connect

These screens can carry more homepage DNA:

- blueprint background cues
- slightly softer shells
- stronger editorial headings

## Work-Led Screens

- builder
- tailor
- viewer
- settings

These screens should feel quieter:

- more solid surfaces
- less tint
- stronger grid and alignment discipline
- minimal flourish

## Dashboard

Keep fixed:

- header placement
- master resume status area
- tailored resume list location
- search/sort controls
- top actions

Visual targets:

- keep some blueprint feel in the outer shell
- rows should become clearer and more card-like
- actions should look more trustworthy and less admin-generic
- hierarchy should come from the title, row titles, and action contrast

## Builder

Keep fixed:

- left editor, right preview split
- tab placement
- action toolbar placement
- form section ordering
- preview placement

Visual targets:

- builder is a work-led screen
- editor must feel stable and exact
- preview frame should be restrained
- tabs should feel structural, not bubbly
- action bar should be compact and disciplined

## Tailor

Keep fixed:

- job description input location
- prompt selector location
- generate action location
- status/error/result flow

Visual targets:

- keep a strong editorial input surface
- warning and setup states should be unified and calm
- CTA should remain unmistakable
- page should feel guided, not decorative

## Resume Viewer

Keep fixed:

- document preview placement
- action buttons
- feedback blocks
- delete/download/edit flow

Visual targets:

- viewer is document-led
- chrome should step back from the paper
- feedback should read like curated notes
- page should feel reliable and calm

## Settings

Keep fixed:

- provider section
- feature flags
- language settings
- danger zone

Visual targets:

- settings is a work-led control room, not an admin toy
- status cards should be precise and legible
- controls should feel trustworthy
- danger zone should be distinct but still contained

## Sign In

Keep fixed:

- single Google sign-in CTA
- supporting copy
- back/home link placement unless visually trivial

Visual targets:

- strongest brand softness allowed here
- one decisive action
- minimal clutter

## Extension Connect

Keep fixed:

- connection progress message
- success/error state logic
- close/retry controls

Visual targets:

- transitional surface
- calm, bright, and low-noise
- should feel like a continuation of sign-in, not a utility screen

## Implementation Constraint

When this theme is applied later:

- do not redesign information architecture
- do not move sections between columns
- do not add new panels unless purely decorative
- do not change app logic or sequencing
