# Dashboard Spec

Mode: Brand-led

## Structural Lock

- Keep the page header placement.
- Keep the master resume control in the same action cluster.
- Keep the tailored resumes list where it is.
- Keep search and sort in the same toolbar position.

## Visual Intent

- Let the outer page retain a subtle homepage blueprint field.
- Make the main list shell feel more substantial and less flat.
- Convert list rows into cleaner bright cards with stronger typography hierarchy.
- Keep status chips compact and technical.

## Components To Reskin

- page shell
- top action buttons
- master resume module
- search input
- sort select
- resume rows
- status chips

## Tone

- branded but not decorative
- bright and editorial
- more product confidence, less admin panel
